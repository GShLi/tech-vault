# Frontend

The frontend will be a Vue3 + Vite application. Planned page groups:

- `chat`: primary Q&A workspace, citations and feedback
- `knowledge`: knowledge-base and document management
- `tasks`: ingestion, sync and index-generation status
- `chunks`: chunk preview, edit, disable and rebuild
- `traces`: retrieval debugging
- `evaluations`: golden sets and regression reports
- `model-policy`: provider and data-egress settings
- `admin`: teams, members and system configuration

No frontend runtime is installed in the current development environment yet.
